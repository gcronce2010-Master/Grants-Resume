# Grants Resume

![Grants Resume Banner](https://picsum.photos/seed/grants-resume/800/400)

An AI-powered online resume and portfolio builder. Grants Resume helps you craft professional "About" sections, rewrite job responsibilities for maximum impact, and summarize projects using advanced AI models.

## Features

- **AI Content Generation**: Craft compelling bios and professional summaries.
- **Experience Rewriting**: Transform raw job duties into achievement-oriented bullet points.
- **Project Summarization**: Build impactful project cards from evidence and descriptions.
- **Live Preview**: See your resume exactly as it will appear to recruiters.
- **QR Code Integration**: Easily share your digital portfolio with a unique QR code.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS & ShadCN UI
- **AI Engine**: Google Genkit with Gemini 2.5 Flash
- **Language**: TypeScript

## Getting Started

To get started, navigate to the `/profile` page to begin entering your basic information, work experience, and education history.
