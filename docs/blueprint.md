# **App Name**: ResumeKeeper

## Core Features:

- User Profile Management: Create and update personal details, experience, and education history with built-in validation for specific data rules like 3 responsibilities per job.
- AI-Powered 'About' Content: A generative AI tool to assist in drafting an 80-120 word 'About' paragraph and a concise 1-2 sentence short bio.
- Project Portfolio Management: Add projects by URL or file upload, ensuring each includes at least one evidence source. Includes full edit and update functionality.
- Dynamic Resume/Portfolio Preview: Render a clean, professional, and accessible online portfolio layout from all saved data, allowing users to preview their final output.
- Content Validation: Client-side and server-side validation to enforce data rules for 'Experience' and 'Projects' sections.

## Style Guidelines:

- Primary brand color: A deep, professional blue (#2666A6), symbolizing trust and clarity. It offers excellent contrast against lighter backgrounds for readability.
- Background color: A very light, almost white, cool grey (#EFF2F5) with a subtle blue tint to maintain a clean and airy feel, enhancing accessibility.
- Accent color: A vibrant yet soft sky blue (#2BB0E0), providing a fresh visual highlight for interactive elements and calls to action without overpowering the main content.
- All text will use 'Inter', a grotesque sans-serif font known for its modern, clean, and highly readable characteristics across various screen sizes. It supports a professional and objective aesthetic suitable for a resume.
- Utilize simple, outline-based icons with a consistent line weight. Icons should clearly communicate their function, adhering to modern UI best practices for accessibility and ease of understanding.
- Adopt a clean, spacious, and modular layout with ample whitespace. Information should be organized into clearly defined sections, employing a responsive grid system to ensure optimal display on all devices.
- Implement subtle and purposeful animations, such as smooth transitions for tab switching or modal appearances. These animations should enhance user experience by providing visual feedback without distracting from content.
